# YouTube to mp3 converter
This is YouTube to mp3 converter that extracts audio from video to mp3 format

![Preview](images/youtubetomp3.png)

## Functional
The app allows to paste link via clipboard or drag and drop; after insertion download button appears. There is ability to download several audio simultaneously or delete any selected of them

![Instruction](images/youtubetomp3.gif)

## Audiotrack quality
Bitrate: 320 kbps  
Sample rate: 44100 Hz  
Channels: stereo

## Stack
\- Java  
\- FFmpeg
